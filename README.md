# THEREFORE · 그러므로

> 인생은 초등학교에서 배운 것의 복습이란다

교육론, AI 활용, 그 밖의 생각을 모아 두는 글 아카이브.

ELSEWHERE(다른 곳)와 HERE(여기)에 이은 세 번째 사이트다. 세 이름은 모두 HERE를 품는다.

```
elsewHERE · HERE · tHEREfore
```

| 사이트 | 다루는 것 | 저장소 |
|---|---|---|
| ELSEWHERE | 해외 여행기 | burntbread-jpg/elsewhere (공개) |
| HERE | 국내 장소 지도 | burntbread-jpg/here (비공개) |
| THEREFORE | 생각 · 글 | burntbread-jpg/therefore (공개) |

## 현재 상태

기획 단계. 아직 코드는 없다. 결정 사항과 남은 질문은 [docs/HANDOFF.md](docs/HANDOFF.md)에 있다.

## 예정 스택

ELSEWHERE와 같은 방식: Astro + MDX + Tailwind + TypeScript, pnpm, 정적 출력. 글은 Git 저장소의 MDX 파일로 관리한다(글쓴이 1명).
